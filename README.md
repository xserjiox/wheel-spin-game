# Крути

Лёгкое колесо случайного выбора на чистых HTML, CSS и JavaScript — без сборщика и зависимостей.

## Запуск

Откройте `index.html` в браузере или запустите любой статический сервер в этой папке, например:

```bash
npx serve .
```

Название и варианты сохраняются локально в браузере. Каждый сектор имеет одинаковую вероятность: `100 / количество вариантов`.
